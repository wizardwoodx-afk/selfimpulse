# 11Handle 19.7 — UPGRADE NOTES

**Product:** 11Handle · **Engine under the hood:** 19.7.15 ("Handle") · **Demo of record:** Synthetic Industrial Ltd (invented) — signatory A. Raghavan, GM Finance.

These are the release notes for the current product release — desktop-first, everything inside — including the bundled browser service.

## What is in this release

- **The complete platform** — the full application as it was scoped, not a trimmed edition: the Captain/Lead/Crew org, the 30 desks, fleet & drivers, receipts and custody, GuardRail, RSIRALS improvement loops, two-user pairing, mission loop.
- **Documents wing** — read the files a business actually has: PDF, DOCX, PPTX, XLSX (text extraction + classification).
- **Finance wing + the demo of record** — huge Excel ledger **sorting & classification** for **Synthetic Industrial Ltd** (signatory: A. Raghavan, GM Finance), 5,200 rows, FY 2025-26.
- **Wings inside** — ORG (Captain → Lead → Crew routing), REACH (channel policy + inbound safety scan), CONNECTORS (mail/calendar/sheets/finance intake, risk-tiered).
- **Offline verification pack** — `node verify/run.mjs` reproduces the full probe gate with zero install.

## The demo (one command)

```bash
node tools/make-finance-demo.mjs
```

Writes `demo/Synthetic-Industrial-FY26-RAW.xlsx` (5,200 rows, chaos: mixed date formats, blank parties, an exact duplicate, a board-note misc row, a credit note) and `demo/Synthetic-Industrial-FY26-CLASSIFIED.xlsx` (sorted, 12 categories, confidence %, quality flags, month), plus SUMMARY + RECEIPT. Ask "sort and classify our ledger" → Finance desk. The story rows are in there: Coastal Steel Supply ₹4,58,000 → RAW-MATERIALS; the duplicate freight lines → flagged; the ₹27,50,000 "misc settlement as per board note" → MISC + REVIEW-HIGH-VALUE; the −₹38,000 credit note → NEGATIVE-AMOUNT.

## Run it

```bash
unzip 11Handle-<version>.zip -d 11Handle && cd 11Handle
npm install
node tools/make-finance-demo.mjs     # the synthetic industrial demo artifacts
npm test                             # the full probe gate — every suite
node verify/run.mjs                  # the same gate, offline, zero install
```
