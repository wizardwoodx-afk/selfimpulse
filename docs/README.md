# Documentation

SelfImpulse is the product; SelfImpulse is the engine underneath it. The
documents here describe the engine's design and how to verify it. None of them
carry a product version — the runners report their own counts.

## Live documents

- `VERIFICATION.md` — the two-tier verification gate (offline pack + full toolchain)
- `PLATFORM-LIMITS.md` — what the product does not do, stated plainly
- `RSIRALS.md` — bounded self-improvement and its external verifier
- `POSITIONING.md`, `UNIQUE-FEATURES.md`, `STORY.md` — positioning and narrative

## History

`history/` holds the engine's complete versioned record under its original
name — release notes, upgrade guides, verification records, design notes
(information architecture, interop, RSI framework, code splitting, roadmap,
enterprise thesis, demo script) and the previous README/FEATURES. `history/releases/CHANGELOG.md` and
`history/releases/RELEASE-VERIFICATION.md` are the authoritative build
records; they are archived as written and are not rebranded.
