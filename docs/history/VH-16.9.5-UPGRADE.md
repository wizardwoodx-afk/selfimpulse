# VH 16.9.5 — the focused release (doc-identity gate, real-model brain seam, signed security review)

*Vouch Harbor 16.9.5 — the accountable agent OS (govern · execute · verify · learn).*

The 16.9.1 external review set the next-release priorities: "real-model Vouch
brain integration + external security review + exhaustive release-document
scanning, not another large feature subsystem." 16.9.5 ships exactly those
three, on the proven 16.9 engine, with no engine-path change.

## The three features

- **Exhaustive doc-identity scanning** — `probe/docIdentity`: every current
  Markdown document (repo root + docs/, excluding the history ledger and
  CHANGELOG by design) is scanned for release strings in both `16.x.y` and
  `v16.x.y` forms; historical references are allowed only in named context
  (release notes, docs/history links, POINTER/WINDOWS-FIX mentions,
  supersed/retired/legacy phrasing); anything else that is not the single
  `VH_VERSION` FAILS the release. The finding that prompted it — the
  one-pager, deck outline, information architecture and platform-limits
  docs still naming 16.9.0 — is fixed in the same turn, including stale
  count claims (now 95 suites / 94 bundles).
- **The real-model brain seam** — `src/vouch/engine/brainSeam.ts` +
  `probe/brainSeam`: the conversational brain (rule-based, labeled
  "simulated" since 1.0, the extension point documented in the source) can
  now route its PLAN step through a REAL agent CLI from the product's own
  25-harness registry — the drill's install detection and spawn policy, so
  detection and argv cannot drift. The seam spawns for real or REFUSES IN
  WORDS (unknown harness, not installed, non-zero exit, timeout, empty
  answer — never a fake run, no silent fallback); every run is labeled in
  the plan's thoughts (harness, duration, "still gated"); the browser
  edition and CLI-less hosts refuse honestly; and the preference is a
  human decision, OFF by default (`vh.brain.pref = simulated | auto`).
  The wrapper is dependency-injected — the probe drives success, refusal,
  failure, timeout and the real host's honest absence without any model.
- **The security-review artifact** — `src/mission/securityReview.ts` +
  `probe/securityReview` + an Audit-door card: `vh-security-review/1`, the
  deliverable 16.6.0 named as planned. Every security surface inventoried
  with its posture AND a machine-checkable evidence pointer (probe suites,
  gates, the zero-install verifier); findings stated in words (no external
  penetration test, single-host threat model, drill seats are machinery not
  model intelligence); explicit refusals of overclaims (no regulatory
  certification, no vulnerability-freedom claim, no model-correctness
  claim); SHA-256 digest over the canonical body, Ed25519-signed by the
  receipt issuer keychain when a key exists — the unsigned path is stated.
