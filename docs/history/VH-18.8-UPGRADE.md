# Vouch Harbor 18.8.0 "Atlas" — upgrade notes

Base: 18.7.0 "Keystone". 18.8.0 is the catalog release the 18.7.0 review
called for: the specialist bench grows **147 → 252 real specialists** across
the ten domains, each one individually specified — no placeholders, no
padded counts, the honesty rule untouched. The packaged web build is
regenerated so it no longer lags source. Protocol unchanged at v0.10.7.

## 1 · The bench: 147 → 252 (+105 real specialists)

Every new entry carries its own capabilities, routing vocabulary, an honest
risk tier and an actual system prompt with a stated working rule (evidence
before claims, reversibility before force, measure before optimize).
Domain totals after the expansion:

```text
code 41 · security 30 · devops 26 · testing 24 · research 24
data 23 · analysis 21 · design 21 · writing 20 · review 18  (+4 ops)
```

Highlights of what the bench can now field natively:

  • **code** — C++/Java/iOS/Android/Flutter/Node platform engineers,
    profiling, concurrency, error-handling architecture, i18n, a11y, regex
    safety, hermetic builds, state sync (CRDT conflict policies), background
    jobs, instrumentation, dependency upgrades.
  • **security** — threat modeling, advisory reachability triage, secrets
    rotation planning, authn/authz design, TLS, container runtimes, web
    exploitation review, supply chain, privacy-law mapping, engagement
    scoping, incident response (critical tier), rate-limit abuse, passkeys.
  • **testing** — journey flows, CI pipeline strategy, test doubles, flaky
    triage, test data, cross-browser matrices, device labs, production
    parity, suite prioritization, runnable docs.
  • **review** — PR workflow, diff hygiene, performance review, changelog
    review, DX review, dependency adoption, failure modes, API compatibility.
  • **data** — entity resolution, geospatial, feature engineering, BI
    dashboards, anonymization, batch-vs-stream, schema evolution, backfill
    ops, catalog/metadata, lakehouse formats, numeric integrity (money is
    never float).
  • **devops** — IaC modules, SLO/error budgets, platform engineering,
    runner fleets, upgrade drills, log pipelines, certificate lifecycle,
    environment parity, workload scheduling, postmortems, JIT access,
    production failover (critical tier).
  • **research / writing / analysis / design** — tech radar, evidence
    synthesis, survey design, fact-checking, prior art, scenario planning,
    reproducibility, vendor evaluation, clarity editing, naming taxonomy,
    migration guides, status communication, KB architecture, exec summaries,
    metrics/KPI rigor, anomaly detection, unit economics, attribution,
    sensitivity, data storytelling, churn drivers, ops analytics,
    interaction prototypes, brand language, design QA, empty/error states,
    form design, iconography.

Risk tiers were assigned honestly: destructive/production-touching work
(failover, backfills, schema evolution, C++ memory, concurrency, engagement
scoping, TLS, secrets rotation, JIT access) is `risky`; incident response
and production failover are `critical` — they always pause at the human
gate, autonomy never touches them.

The catalog computes its own count (`catalogStats().count`) — the door,
probes and docs report what exists, never what marketing wants.

## 2 · The packaged web build no longer lags source

The 18.7.0 review noted `web-build/` could ship older than `src/`. This
release regenerates it from the same tree the gates run on, and the release
notes state that plainly.
