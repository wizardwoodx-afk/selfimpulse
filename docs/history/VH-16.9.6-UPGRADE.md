# VH 16.9.6 — the honesty patch (truthful brain identity, zero stale strings, precise language)

*Vouch Harbor 16.9.6 — the accountable agent OS (govern · execute · verify · learn).*

The 16.9.5 external review (9.8/10, "keep as trunk") named two fixes required
before the release could be called externally polished. Both are closed here —
and pinned so the class of drift is extinct, not just corrected.

## The fixes

- **Truthful brain identity** — the 16.9.5 review caught an identity
  inconsistency: the wrapper kept `id: "simulated"` even when `auto` mode got a
  real-model plan, so one surface could say "REAL model — Claude" while another
  said "Brain: Simulated". The wrapper's `id`/`label` are now live getters:
  seam enabled → `simulated+real-plan` with a label that names both the hybrid
  capability and its honest limit ("refusals are in words, never faked");
  seam disabled → the base identity, unchanged. The UI reads the live brain,
  so every surface agrees by construction.
- **Zero stale product strings** — the review found the product logic saying
  "a provider connected through the brain seam (next release)" (false: it
  ships in 16.9.5) and "dispatch … honestly refused until the mission engine
  is merged in (Step 3)" (false: the VH engine merged at 16.0). The welcome
  copy and the fallback now state the current truths, including the merge
  lineage, and runtime info reports the LIVE brain id instead of a hardcoded
  "simulated (offline)".
- **Language precision** — the seam names itself a **real-model PLANNING
  seam**: route, recall, act, gate and learn remain the governed runtime's;
  the real model proposes the PLAN. The module header names the next
  milestone in words (real model → full Vouch reasoning/context → governed
  tool selection → mission execution → proof → verified learning) and never
  claims a "fully real-model brain".

## Pinned, not just fixed

`probe/brainSeam` grew nine assertions: the hybrid identity in auto mode, the
base identity when off, the absence of every stale string (`next release`,
`until the mission engine is merged`, the hardcoded runtime label), the
presence of the merge truth, and the language-precision pins. This class of
drift now fails the release.

## What did NOT change

The governed pipeline, the receipt protocol, the human gate, the MCP surface,
and the release counts: **95 live suites / 94 offline bundles** (tsc 0, vite
clean, cold-extraction archive verified).
