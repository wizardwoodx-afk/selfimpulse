# Vouch Harbor 18.6.0 "Polaris" — upgrade notes

Base: 18.5.0 "Apex". 18.6.0 is the identity release: the product stops
looking like the generic chat surface every AI tool copies and starts
looking like what it actually is — a receipt ledger. New motion grammar,
matured type and chrome, a clean tree. Protocol unchanged at v0.10.7;
suites unchanged at 113 live / 112 offline bundles.

## 1 · The door is a log, not a chat

The VH-19 conversation is now **the log**: numbered entries (Nº 001…),
timestamps, hairline dividers, and outcomes as rubber stamps — `ANSWERED ·
EXECUTED`, `PLAN ONLY`, `PAUSED AT GATE`. User entries read as right-set
margin notes rather than bubbles. The metaphor is the product's own — every
entry is a receipt, and the ledger makes that visible at a glance. Nothing
in the semantics changed; every routing detail, proof digest, and
accept/reject control is exactly where 18.5.0 had it.

## 2 · New motion grammar (reduced-motion safe, all of it)

  • **Horizon arc** — VH's signature: on every view change a thin arc draws
    itself across the top of the viewport (620ms quint). It is the app's
    only ornament and it is on-brand geometry, not confetti.
  • **Tide bar** — engine state you can feel: breathes while VH is working,
    goes amber and still while a gate is paused, rests when idle. Replaces
    the spinner idiom with something calmer and more legible at a glance.
  • **Staged ledger entries** — log entries enter with a 40ms cascade
    (capped 240ms) and outcome stamps pop in with a settle.
  • Cards now recede until touched: hairlines brighten on hover, nothing
    floats.

## 3 · Matured chrome

Display titles move to 30px / -0.03em / 650 weight — quiet confidence
instead of hero noise. The viewport carries a three-stop depth gradient
(#141416 → #121214 → #101013) instead of flat fill. Contrast hierarchy
tightened: metadata (entry numbers, timestamps, digests) drops to the aged
tier so the receipt content owns the foreground. Palette unchanged — the
Horizon tokens stay the system of record.

## 4 · Clean tree

Generated icon masters removed from `public/` (the icon ships from the
checked-in SVG + the documented generator command). No product file names
outside software by name; the category research that informed 18.5–18.6
stays in the project's private records.

## 5 · Version identity & gates

18.5.0 → 18.6.0 ("Polaris") across every manifest and current-facing doc;
`release.yml` pins VH-18.6-UPGRADE.md; offline pack, MCP and host engine
bundles regenerated and re-pinned.
