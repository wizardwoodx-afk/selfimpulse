# Vouch Harbor 18.3.0 "Meridian" — upgrade notes

Base: 18.2.0 "Horizon". 18.3.0 is the hardening-and-polish release the
external review ordered: the two cryptographic findings are fixed, the app
gains quiet motion and a new mark, the bundle splits, and the browser build
gets a CSP. Protocol unchanged at v0.10.7.

## 1 · The attacker-key hole, closed (review finding #1)

`verifyApproval` in 18.2.0 verified against a public key carried INSIDE the
approval, so a fresh attacker keypair wearing "qwen" as a name would verify.
Now `src/vh19/collabRegistry.ts` holds BOUND identities, and verification
resolves the expected approver's key from the binding: an unbound member
refuses, a presented key that does not deep-equal the bound one refuses, and
the signature is checked against the bound key. Binding is an explicit human
act — accepting an invitation binds the issuer in the same click, manual bind
covers the rest, unbind is one click. `probe/collabInvite` pins the attacker
scenario directly (23 checks). Bonus hole found while pinning: signed
approvals over an OLD proposal digest verified — `approveTeamEvolution` now
refuses stale digests too.

## 2 · Private keys out of localStorage (review finding #2)

`src/vh19/secureKeys.ts`: private halves are AES-256-GCM encrypted under a
PBKDF2-SHA-256 (150k iterations) derivation of a user passphrase that is
never stored; decrypted keys live in a session-only in-memory map; a locked
identity cannot sign or mint invites; a wrong passphrase refuses in words.
Legacy 18.2.0 plaintext blobs are PURGED on first contact — treated as
breached, not migrated. What this is not, and says so: it is not an OS
keychain and not a hardware boundary. The documented upgrade path is Tauri
IPC to the native credential store; no unverifiable Rust is shipped here
(this sandbox cannot compile Rust, and we do not ship what we cannot verify).

## 3 · Motion — quiet, and the OS wins

A Horizon motion system in `atelier.css`: 140–260 ms entrances with one
quint ease (views rise 7 px, messages 5 px, toasts slide, buttons micro-press
at 100 ms, the live seal dot breathes, streaming shows a shimmer). No
parallax, no springs. `prefers-reduced-motion` collapses everything to
0.01 ms. Pinned by prose here; enforced by the media query everywhere.

## 4 · A new mark

The previous icon is retired. New identity: a single thin sage arc over a
small platinum ring on near-black — a horizon, a seal, nothing else.
Regenerated across `src-tauri/icons/*` (`.png`, `.ico`, `.icns`), favicon and
the sidebar seal share it. No letterform, no gimmick.

## 5 · Performance — the bundle splits for real

The CODE-SPLITTING roadmap ships step 1 and 3: every dock except the VH-19
front door is `React.lazy` (Harbor, Ship, Chart, Register, Harbor Master,
Settings each land as their own on-demand chunk; react stays its own
long-cached vendor chunk). Main chunk 552 kB → 528 kB with the engine + door
synchronous by decision. `npm run build` prints the per-chunk table; the
honesty clause in `docs/CODE-SPLITTING.md` stands: measure before and after,
engine stays in the first paint.

## 6 · Browser-build CSP

`src/main.tsx` injects a Content-Security-Policy in non-Tauri builds
(default-src 'self', https-only connects, no objects). Desktop keeps the
Tauri CSP untouched — the intersection would have blocked the webview's
asset protocol, so the meta is deliberately browser-only.
