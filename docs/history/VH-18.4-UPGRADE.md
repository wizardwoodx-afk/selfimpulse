# Vouch Harbor 18.4.0 "Zenith" — upgrade notes

Base: 18.3.0 "Meridian". 18.4.0 is the hardening-and-depth release the
pre-seed review ordered: no new architectural layers — the two remaining
cryptographic nits closed, the verification path made reproducible on a
bare machine, and real execution depth added to the bench. Protocol
unchanged at v0.10.7.

## 1 · The identity record must prove itself (review nit, closed)

`ensureIdentity` in 18.3.0 trusted the stored `publicJwk` while decrypting
the private half separately. Now, before an identity is treated as healthy,
the public components INSIDE the decrypted private JWK must equal the stored
public JWK — a tampered metadata row refuses even with the right passphrase,
and stays locked. `probe/collabInvite` pins it (29 checks).

## 2 · Structural binding via the A2A card (review roadmap, first step)

The bound-peer registry was TOFU in browser storage. The A2A layer already
verifies a peer's AgentCard JWS against the pinned publisher key before any
traffic; `a2aIdentityBridge` now records THAT key, and `requireBoundKey`
resolves it: a connected, card-verified peer binds WITHOUT first-use, an
attacker key against an A2A-bound member still refuses, and manual/TOFU
bindings still win when present. The vh19 engine reads the bridge store by
well-known key — no mission imports, the self-contained pin holds. The
terminus (native secure storage) remains documented and un-shipped-pretending.

## 3 · Verification without node_modules

The 18.3.0 review could not reproduce the gates because the archive ships no
dependency tree and the reviewer ran the dev probes (which need esbuild). The
archive already contained the zero-dependency answer — `node verify/run.mjs`,
the 111-suite offline pack. 18.4.0 makes it unmissable: `sh VERIFY.sh` at the
archive root runs it (honesty note in the script: the protocol selftest is
NOT zero-dep — it needs @hpke/core — and says so), README leads with it, and
RELEASE-VERIFICATION says so on line one. Reproducibility on a bare,
offline machine is now a one-liner.
