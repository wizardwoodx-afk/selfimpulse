# Vouch Harbor 19.5.6 "Reach" — upgrade notes

19.5.0 changed the trust model. 19.5.1 gives VH hands and closes every
document at the current release.

## What 19.5.1 ships

### Computer-use plane (`src/vh19/computerUse.ts`, 15 probe pins)
- **`pc.exec`** — allowlisted binaries only; shell-metacharacter injection
  scan on arguments; hard timeout; output ceiling; every run receipted.
- **Built-in headless browser** — detects a real browser binary
  (chromium / google-chrome); one isolated BrowserProfile per mission
  (cookies off by default); HTTPS-by-policy navigation; critical actions
  hand over to the human gate; screenshots run through the real binary and
  **refuse wordingly when no binary exists — a page is never faked**.

### The 760 fleet (`src/vh19/reachBench.ts`)
+140 individually specified specialists for the computer-use era — browser
automation, RPA, scraping ethics, automation governance, receipt review,
automation law, trust design. The count is self-proving: 460 seed + 160
broader + 140 reach.

### Hardened Authority layer (`probe/authority` — 34 pins)
- **Asymmetric mandates**: ECDSA P-256 — the owner signs, anyone verifies
  with the public key. Symmetric HMAC is explicitly refused as portable
  authority; one trust root with VH's identity model.
- **Authority ⟷ receipt-chain binding**: every hop binds to a receipt digest;
  either side verifies offline.

### VOUCHMESH™ (19.5.0, carried forward)
Registered peers · mutual attestation · joint receipts co-signed by all
participants · compounding pair trust · quarantine with a receipt.
