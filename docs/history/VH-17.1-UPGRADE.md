# VH-17.1-UPGRADE — Vouch Harbor 17.1.4 "Patina"

This is a hardening release: the Patina shell is now wired to the real engine.

## What's fixed since 16.10.2 / 17.0 / 17.1.0

1. The Patina five-door shell (Harbor / Ship / Chart / Register / Harbor Master + Helm) was redesigned in 17.0 but sat on a simulated timeline. 17.1 replaces that with `src/app/harbor.tsx`, the single runtime bridge. Every view reads live engine state. Every submission goes through `sendVouchMessage()` — the governed ROUTE→RECALL→PLAN→THINK→SIMULATE→GATE→ACT→VOUCH→LEARN cycle.
2. Pending approvals surface in the sidebar badge and on Harbor, with working Approve / Deny.
3. Register's Verify button actually runs `verifyVouchReceipt()` (SHA-256 / HMAC / Ed25519). JSONL downloads are real chained receipts.
4. Harbor Master → Windward reads from the real provider registry: add / remove providers, set API keys, toggle real-model routing.
5. Harbor Master → Backtest → Run the drill calls `runDrill()` for the three real scenarios.
6. Harbor Master → Sweep scans this machine's stored credentials for orphaned keys.
7. Chart renders a live topology from the current brain / seats / gate / seal.
8. Ship shows real vouched skills (wins/runs/flags) with working Unlearn.
9. Version drift is fixed: `version.ts`, `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, `src-tauri/tauri.conf.json`, `verify/BUILD-INFO.txt`, `verify/MANIFEST.json`, `README.md`, and all BUILD/INSTALL docs agree on **17.1.4**.
10. `probe/patinaShell.test.ts` is new: it guards against the "beautiful UI → inert handler" regression class that 17.0 shipped with.

## Four new differentiators that didn't exist in 16.10.2

- **Signed Delegation Chain Ledger** (Harbor Master → Lineage).
- **Ghost Agent Sweep + Zero-Residual Receipt** (Harbor Master → Sweep).
- **Backtest Replay Bench + The Drill** (Harbor Master → Backtest).
- **Hindsight Ledger** (Register — counterfactual plan drift per receipt).

## Install

```bash
npm install
npm run dev              # web
npm run tauri dev        # native desktop
```

Default brain is the simulated (offline, honestly labeled) one. Add an API key in Harbor Master → Windward to enable real-model planning.
